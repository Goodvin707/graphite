# Нить

Бесплатное локальное хранилище заметок с графом связей. Это самостоятельная программа в браузере: без аккаунта, без подписки и без отправки текста на сервер.

Заметка пишется на Markdown. Фраза `[[Другая заметка]]` становится ребром графа. `#тег` собирает тему. Если ссылка ведёт в пустоту, на графе появляется призрак — кружок заметки, которой ещё нет.

## Как пользоваться

- **Весь граф** показывает хранилище целиком. Размер узла зависит от числа связей, цвет — от папки.
- Наведите курсор на узел: подсветятся соседи. Двойной щелчок открывает заметку. Колесо мыши приближает, перетаскивание фона двигает полотно, перетаскивание узла закрепляет его.
- **Вокруг заметки** оставляет только окрестность открытой заметки. Глубина 1, 2 или 3.
- В настройках графа можно спрятать сирот, спрятать призраки, показать теги отдельными узлами, перекрасить по тегам и скачать картинку.
- Поиск в шапке фильтрует список и приглушает на графе всё, что не совпало.
- Данные лежат в `localStorage` этого браузера. Меню справа вверху экспортирует и импортирует JSON.

При первом открытии загружается пример «Мастерская»: сад, книги, люди и метод заметок, чтобы граф сразу был живым. Его можно заменить пустым хранилищем.

Клавиши: `Ctrl`/`⌘` `K` — поиск, `Ctrl`/`⌘` `N` — новая заметка, `Ctrl`/`⌘` `Shift` `G` — переключить граф и текст.

## Что нужно для запуска

Одинаково на Windows, Linux и macOS:

- **Node.js 22 или новее** и **npm**, который ставится вместе с ним. Сам сайт открывается уже на Node.js 20.9, но `npm test` читает TypeScript встроенными средствами Node и поэтому требует 22.6 или новее.
- Современный браузер: Chrome, Firefox, Safari или Edge. Отдельной базы, аккаунта и ключей нет: заметки остаются в `localStorage` этого браузера.
- Свободный порт **4731**. Если он занят, сервер не стартует. Порт задан в скриптах `dev` и `start` в `package.json`.

Компилятор C++, Python и Git для запуска не нужны. Git нужен только чтобы склонировать репозиторий.

Проверка после установки, в новом окне терминала:

```bash
node -v
npm -v
```

`node -v` должен показать `v22` или выше.

### Windows

1. Скачайте установщик LTS с [nodejs.org](https://nodejs.org) и при установке оставьте пункт добавления Node в `PATH`. Либо в PowerShell:

```powershell
winget install OpenJS.NodeJS.LTS
```

2. Закройте терминал и откройте его снова, иначе `node` и `npm` не найдутся.
3. Перейдите в каталог проекта и запустите его командами из раздела ниже. Подойдут PowerShell, cmd и терминал Windows.

### Linux

Пакет `nodejs` из репозитория дистрибутива часто старше, чем нужно. Если `node -v` меньше 22, эта установка не подойдёт.

Поставьте Node.js 22 LTS с [nodejs.org](https://nodejs.org) (раздел Linux) или через менеджер версий [nvm](https://github.com/nvm-sh/nvm) либо [fnm](https://github.com/Schniz/fnm). После установки откройте новый терминал и снова проверьте `node -v`.

### macOS

Скачайте установщик LTS с [nodejs.org](https://nodejs.org) или, если стоит Homebrew:

```bash
brew install node
```

Закройте терминал и откройте его снова, затем проверьте `node -v`.

## Запуск

В каталоге проекта:

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:4731](http://127.0.0.1:4731). Остановить сервер: `Ctrl+C` в том же терминале.

Сборка для обычного запуска без режима разработки:

```bash
npm run build
npm start
```

Адрес тот же. Проверки:

```bash
npm test
npm run lint
```
